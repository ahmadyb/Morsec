# Reviewed SHA-256 digests for the security-critical Milestone 4 Part B artifacts.
#
# WHAT THIS IS
#   The exact bytes this repository intends to consume for the TLS provider and the
#   certificate/signature library. CI computes the SHA-256 of the artifact Gradle actually
#   resolved out of its module cache and compares it to the value below, so a substituted,
#   truncated or corrupted artifact fails the build instead of being compiled into an APK.
#   Any future change to these digests is a one-line diff that has to survive review.
#
# WHAT THIS IS NOT
#   It is not provenance. These digests were taken from Maven Central, which is also where
#   Gradle downloads from, so a match proves the bytes in the build cache are the bytes
#   Maven Central serves -- not that they are the bytes Conscrypt or Bouncy Castle signed.
#   Proving that needs signature verification against the vendors' keys, which this
#   repository does not do. See doc/security/milestone-4-part-b.md, "Dependency bytes".
#
# SCOPE
#   Deliberately limited to the artifacts that perform cryptography or feed it: the bundled
#   TLS provider and the three Bouncy Castle modules in the resolved runtime graph. It is
#   not a whole-graph lock; the remaining AndroidX/Kotlin/Gradle transitives are pinned by
#   coordinate only. Expanding coverage means reviewing and adding digests here, not
#   generating them wholesale and trusting the output.
#
# FORMAT
#   <group>:<name>:<version> <extension> <sha256-hex-lowercase>
#
